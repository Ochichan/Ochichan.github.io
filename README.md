# Ochichan.github.io

Public website for [StarryStudio](https://ochichan.github.io), a one-person studio by Ochi.

GitHub Pages serves this repository as a static user site from the repository root. Open `index.html` in a browser to preview. There is no build step.

The page is bilingual (Korean and English), with short introductions to the studio’s games and Mac apps and a contact link to `dev@starry-studio.net`.

These root files stay in place for existing checks and should not be removed:

- `app-ads.txt` — AdMob app-ads.txt
- `googlea30aa21077293016.html` — Google Search Console site verification

Moss Idle policy pages remain at [https://ochichan.github.io/moss-idle-site/](https://ochichan.github.io/moss-idle-site/).
